## 1. 设计原则(先于布局)

| # | 原则 | 与马尧现状对比 |
|---|---|---|
| 1 | **第一秒让她觉得"她懂我"**——关系货币优先,认知货币次之,成就货币最后 | 现状:六维评分 + 喜猫 = 工具/客服感 |
| 2 | **删除关卡升级**——健康不是通关,L1-L5 是教育产品语言,错位 | 现状:L1-L5 关卡升级体系 |
| 3 | **医学 IP 的脸 + 声音是主角**——不是吉祥物,必须是真人 | 现状:喜猫吉祥物 = 没有信任锚 |
| 4 | **今日只有 1 件事**——不是 5 个 KPI,认知负荷决定执行率 | 现状:本周 4 次 30 分钟 + 4 项 AI 建议(像学习营 SOP) |
| 5 | **围绝经词汇明确出现**——命名即疗愈 | 现状:0 个围绝经词汇 |
| 6 | **同行人故事 = 第二个信任锚**——比医学 IP 更可信的同年龄案例 | 现状:无社群无故事 |
| 7 | **数据快照 4 张,不是 8 张**——围绝经核心信号优先 | 现状:核心指标 8 张 + 雷达 = 过载 |
| 8 | **家庭账户埋暗线,不弹窗**——自然拉新乘数 | 现状:无家庭账户入口 |

## 3. 区块详细规格

### 区块 A · 顶部状态条

**功能**:品牌识别 + 通知入口
**布局**:左产品 logo(健康知己),右通知小铃铛
**对比马尧**:删掉"风险识别中"那个 banner 卡片(那是焦虑营销,与"健康知己"叙事冲突)

---

### 区块 B · 医学 IP 音频简报 ★ 灵魂区

**这是整个首屏唯一不可妥协的区块。如果只能保留一个 feature,保留这个。**

**布局**:
- 左:医学 IP 头像(圆形,真实女性医师照片,不能是插画)
- 右:文字 3 行
  - 第一行:"李医生 · 你的健康知己"(IP 身份)
  - 第二行:今日开场白(基于昨晚数据生成,12-18 字)
  - 第三行:播放按钮 + 时长(▶ 3:24)
- 全卡可点 → 进入播放页

**3 个状态机示例文案**:

| 用户状态 | 今日开场白(显示在首屏) |
|---|---|
| 冷启第 1 天 | "我是李医生。你愿不愿意我们先聊清楚最近的身体——" |
| 侦察期第 12 天 | "你这周 5 个晚上都在 3 点醒来。我录了 3 分钟——" |
| 同行期第 45 天 | "23 天前你说 23:30 睡不着。今天我看你的数据——" |

**实现技术路径**:

**Phase 1 MVP(0-3 个月,医学 IP 未锁定)**:
- 产品经理 + 临时医学顾问真人录制
- 周一固定"周状态总览"3 分钟 + 周三周五"专题"3 分钟
- AI 只做"开场白文本生成 + 内容片段挑选拼接",不全自动 TTS

**Phase 2 正式版(锁定医学 IP 后)**:
- 真人录制每周 1-2 小时基础语料库(50-80 个 30 秒片段)
- 用户数据接入 → AI 解析昨晚信号 → 从语料库挑选片段 + 拼接 + 个性化文本 → 该医学 IP 声音克隆 TTS
- 自动每天 03:00-05:00 生成 → 07:30 推送

**核心约束**:
- 不允许使用通用 AI 女声 TTS(用户能立刻识别出"假的",信任地基立刻崩)
- 不允许超过 5 分钟(超出注意力)
- 不允许低于 2 分钟(短了显得敷衍)

---

### 区块 C · 今日身体状态(围绝经四维 + 阶段命名)

**布局**:
- 标题"今日身体状态"
- 副标题"围绝经活跃期 · 第 23 天"(阶段命名 + 穿越天数)
- 4 个四维卡片(横排):雌激素 / 睡眠 / 情绪 / 代谢
  - 每个显示状态:关注 / 平稳 / 改善 / 待录入
- 底部 1 句话归因(围绝经命名 + 共情)

**关键设计**:
- **删掉马尧的六维**(运动/代谢/恢复/情绪/风险/连续)→ 改为**围绝经四维**
- 阶段命名(医学严谨):
  - 观察期(月经规律,40+ 准备期)
  - 早期围绝经(月经周期开始波动,FSH 上升)
  - 围绝经活跃期(典型症状出现 — 潮热/失眠/情绪)
  - 绝经过渡期(末次月经前后 1 年)
  - 绝经后(末次月经满 12 个月)
- 阶段判定由 AI 综合 FSH/E2/月经记录/症状日记/年龄 5 维输出

**3 个状态机示例归因句**:

| 用户状态 | 归因句 |
|---|---|
| 冷启 | "把激素六项 + 月经周期录入后,我们再说这条线。" |
| 侦察 | "昨晚 3 点醒来是早期围绝经的典型'夜间觉醒'。E2 偏低 + 凌晨皮质醇上升,这件事说清楚了。" |
| 同行 | "本周潮热 -3 次/周,雌激素水平稳定中,睡眠从 5.1h 提到 6.4h。这是我们一起跑了 23 天的成果。" |

**实现技术路径**:
- 围绝经状态机:基于 FSH + E2 + 月经日记 + 症状日记 + 年龄 5 维分类
- 四维评分:每维度需要至少 3 个数据源
  - 雌激素:激素六项 + 月经规律 + 潮热频率
  - 睡眠:Apple Health 睡眠分期 + 主观记录 + 凌晨觉醒次数
  - 情绪:每日 30 秒情绪打卡 + HRV + 主观日记
  - 代谢:体重 + 体脂 + ApoB + HOMA-IR + 饮食日记

---

### 区块 D · 今天的一件事

**布局**:大卡(占屏 1/3 高度)
- 顶部图标 + 一件事标题(8 字内)
- 中部:医学 IP 第一人称语境(2-3 行)
- 底部 CTA 按钮:[接受陪伴]

**关键设计**:
- **只有 1 件事**,不是 5 个任务
- 必须与昨晚数据相关(否则关系感丢失)
- 必须由医学 IP 第一人称提出(信任锚)
- 必须有"陪你 X 天"的承诺(关系货币)

**3 个状态机示例**:

| 用户状态 | 今天的一件事 |
|---|---|
| 冷启 | 标题:"录入你的激素六项"<br>语境:"这是我能开始帮你的起点。如果近 12 个月做过,直接拍照上传;没做过,我推荐 3 家上海/北京/杭州的同价位机构。" |
| 侦察 | 标题:"23:30 前躺下"<br>语境:"这周陪你 7 天。每晚 23:00 我会提醒你。睡眠这条线一旦稳定,雌激素波动会跟着缓和。" |
| 同行 | 标题:"今天补 30g 优质蛋白早餐"<br>语境:"你的 HOMA-IR 上周降到 1.8 了。本周咱们用蛋白质把代谢拐点再推一步。三个早餐方案我放在了'计划'里。" |

---

### 区块 E · 同行人时刻

**布局**:卡片
- 头部:同行人头像 + 名字 + 年龄 + "同行第 X 天"
- 中部:1-2 句她的话(引号内,带温度)
- 底部:❤️ 数 + "💬 加入她的小群"

**关键设计**:
- **不是"用户故事推荐"**,是"和你状态最像的姐姐"
- 选人逻辑:同围绝经阶段 + 同年龄段 ± 3 岁 + 同主要症状
- 优先呈现"做对了一件事而改善的"姐姐
- 入群入口:点击 → 进入 20 人小群(同状态匹配,医学 IP 入群答疑)

**3 个状态机示例**:

| 用户状态 | 同行人故事 |
|---|---|
| 冷启 | 王姐 · 47 岁 · 第 3 天:"我刚开始也害怕录入激素六项。但李医生让我意识到,这不是给医院看的,是给自己的健康档案。" |
| 侦察 | 王姐 · 49 岁 · 同行第 45 天:"我也是凌晨 3 点醒来三周了,跟着李医生 23:30 习惯走了 4 周,这周开始能睡到 5 点了。" |
| 同行 | 王姐 · 51 岁 · 同行第 156 天:"我现在最大的变化是——不再害怕'变老'这件事。我看到了自己每周变化的数据,这比任何鸡汤都管用。" |

---

### 区块 F · 数据快照(4 张关键卡)

**布局**:4 张小卡横排(可滑动看更多)
- 每卡:数值 + 单位 + 指标名 + 阶段变化(↑/↓)

**关键设计**:
- **马尧现状是 8 张**(步数/睡眠/活动能量/步跑距离/体重/BMI/体脂率/静息心率)→ 改为 **4 张围绝经关键**
- 4 张固定:**睡眠时长 / HRV / 潮热次数 / 心情打卡**
- 其余的(步数/体重/BMI/活动能量)挪到第二屏滑动
- 不显示"理想/关注"标签(避免马尧的阈值 bug)

---

### 区块 G · 本周仪式

**布局**:简洁列表
- 标题"本周仪式"
- 2-3 个 bullet:固定时间 + 事项

**关键设计**:
- **马尧用"任务"模型**(本周完成 4 次 30 分钟运动)→ 改为**仪式模型**
- 仪式 ≠ 任务:仪式有时间锚 + 集体感 + 期待感,任务只有"完成 / 未完成"
- 示例:
  - 周三 20:00  李医生入群答疑
  - 周日 21:00  你的第 4 周复盘上线
  - 月末最后周日 21:00  围绝经同行人圆桌(20 人小群)

---

### 区块 H · 家庭账户暗线

**布局**:1 行小字 + 箭头
- "📔 也为妈妈/老公/女儿开一个健康知己档案 →"

**关键设计**:
- **不弹窗**,不挡路
- 但首屏必有(因为这是 1.5-3 倍拉新乘数的核心入口)
- 点击 → 家庭账户创建流程(单独设计)

---

## 4. 三种状态机下的首屏差异

**为什么需要状态机**:用户在围绝经穿越中的真实状态决定她需要什么。**马尧用 L1-L5 关卡套这个问题——错;正确做法是用"穿越阶段"决定首屏内容。**

### 状态 1 · 冷启(第 1-3 天)

**判定条件**:注册 ≤ 3 天,激素六项未录入,Apple Health 未授权
**首屏目标**:让她相信"这次和别的 App 不一样"
**关键差异**:
- B 区音频简报:"我是李医生。你愿不愿意我们先聊清楚最近的身体——"
- C 区状态:四维全部"待录入",但**已经有围绝经阶段初判**(基于年龄 + 月经周期问卷)
- D 区今日一件事:**录入激素六项 OR 上传体检报告**
- E 区同行人:**"刚开始的姐姐"故事**

### 状态 2 · 侦察期(第 4-21 天)

**判定条件**:Apple Health 已接 + 至少 5 天睡眠数据 + 激素六项已录入
**首屏目标**:让她**第一次被深度看见**——AI + 医学 IP 联合识别出她的关键模式
**关键差异**:
- B 区音频简报:"我看了你这周 5 个晚上的睡眠,发现一个规律——"
- C 区状态:四维有数据,阶段命名清晰
- D 区今日一件事:**最痛的单点改善**(如 23:30 前睡)
- E 区同行人:**状态匹配的"同行第 21 天"姐姐**

### 状态 3 · 同行期(第 22-90 天)

**判定条件**:有 baseline + 至少 1 个习惯已落地 + 1 次月度复盘
**首屏目标**:让她**看到自己的改变**,产生身份认同("我是健康知己同行人")
**关键差异**:
- B 区音频简报:"23 天前你说 23:30 睡不着。今天我看你的数据——"
- C 区状态:出现"改善"标签
- D 区今日一件事:**复合行动**(睡眠 + 间歇训练 + 阳光)
- E 区同行人:**高净值同行人圆桌话题**

## 5. 与马尧健康现状的具体改造对照

### 5.1 删除清单

| 现状元素 | 删除原因 |
|---|---|

| 行动提示横向卡片 | 5 件事改 1 件事 |

### 5.2 新增清单

| 新增元素 | 必要性 |
|---|---|
| 医学 IP 真人头像 + 音频简报 | 信任锚 P0 |
| 围绝经四维 + 阶段命名 + 穿越天数 | ICP 锁定的视觉标记 |

| 本周仪式 | 替代周任务 |
| 家庭账户暗线 | 拉新乘数 1.5-3 倍 |

### 5.3 改造清单

| 现状 | 改造后 |
|---|---|
| 计划 tab 任务 SOP | 改为"穿越日历"(她进入产品第几天) |

## 6. AI 文案逻辑

### 6.1 核心约束

| 约束 | 解释 |
|---|---|
| 不允许通用 AI 套话 | 例如"目前已有几个值得优先处理的关注点" — 一律拒绝 |
| 必须引用具体数据 | 例如"昨晚 3 点醒来"、"E2 25 pg/mL"、"潮热 -3 次/周" |
| 必须有围绝经词汇 | 例如"夜间觉醒"、"皮质醇升高"、"E2"、"FSH" |
| 必须有时间锚 | 例如"第 23 天"、"过去 5 周"、"本周陪你 7 天" |
| 必须有医学 IP 第一人称 | 例如"我看到的是" / "我录了 3 分钟" / "我提醒你" |
| 不允许使用"建议你" | 改用"我陪你" / "我们一起" / "今天我们做" |

### 6.2 围绝经状态归因引擎

输入(每日 03:00 自动跑):
- 昨晚 Apple Health 睡眠分期数据
- 昨天潮热次数 / 情绪打卡 / 月经记录
- 本周 HRV / 静息心率趋势
- 本月激素六项 / ApoB / HbA1c
- 用户穿越天数 / 当前阶段

输出(为今日首屏):
1. C 区一句话归因(20-40 字)
2. D 区今日一件事(8 字标题 + 30-60 字医学 IP 语境)
3. B 区音频开场白(12-18 字)

模型:LLM Prompt 模板,严格遵循 6.1 约束,Golden Set 持续校准。

## 7. 验证指标

### 7.1 短期(改造后 30 天内)

| 指标 | 红线 | 绿线 | 目标 |
|---|---|---|---|
| B 区音频简报播放率 | < 30% | 50%+ | ≥ 60% |
| D 区"接受陪伴"点击率 | < 20% | 35%+ | ≥ 40% |
| E 区同行人入群转化 | < 5% | 12%+ | ≥ 15% |

| 7 天留存 | < 30% | 50%+ | ≥ 55% |
| H 区家庭账户暗线点击 | < 3% | 8%+ | ≥ 10% |

### 7.2 中期(改造后 90 天)
