## 0. 一句话定调

**我们不招"薄世宁",我们招"某个垂直领域的薄世宁"。** 薄世宁(重症医学+通识)的价值是画像模板,不是招募标的。真正要找的是:有他那样的学术硬度 + 内容体系 + 循证方法论,但深耕在**围绝经**(女性灯塔)或**长寿代谢**(男性灯塔)单一垂直赛道的真人医师。

## 3. 男性灯塔候选现实(长寿主权 · 一个重要发现)

### 3.1 关键发现:中国"长寿医学垂直 IP"是市场空白

检索显示,中国**尚无**对标 Peter Attia(长寿医学权威 IP)的成熟人选:
- 现有"长寿/抗衰"内容多为**养生网红、补剂营销、伪科普**(已被多家媒体点名整顿)
- 三甲心血管/内分泌主任医师**普遍未 IP 化**
- 这既是**风险**(招募难度大),也是**机会**(谁先锁定,谁就定义这个品类)

### 3.2 边缘候选与思路
| 候选/思路 | 评估 |
|---|---|
| 张遇升(杏树林 CEO,协和+霍普金斯,得到《精力管理》课) | 懂"健康管理+商业+精力"三位一体,得到课程 3 天 5 万听众;但身份是**创业者/管理者**,非临床信任锚。可作**战略合伙人/操盘手**而非医学 IP |
| 三甲心血管/老年医学主任医师(未 IP 化) | 需"造星"——风险高但可独家锁定、成本可控,符合"自己定义品类"思路 |
| 运动医学/代谢方向中生代医师 | 配合男性灯塔"精力/战斗力"诉求,可培养 |

### 3.3 男性灯塔 IP 策略结论
> 女性灯塔是"**寻找**已成熟的垂直 IP"(白文佩级别已存在);男性灯塔是"**孵化/定义**一个尚不存在的品类 IP"。两条路径不同,男性灯塔的 IP 锁定难度更高、周期更长——**这进一步印证:男性灯塔的入口应靠数据/检测/预测,而非依赖一个现成的 IP**。
