# 第二部分 · 长期价值穿透(LTVI 框架)

## 2.1 商业模式真金白银测试

| 维度 | 健康知己 | 判定 |
|---|---|---|
| 一句话说清 | "把你散落 10 个地方的健康数据,统一管起来,告诉你下一步该干啥,陪你照着做" | ✅ 小学生能听懂 |
| 利润质量 | 订阅毛利 60-85%,无硬件库存,无应收账款,自由现金流即营收 | ✅ 真金白银 |

**商业模式判定:这是巴菲特喜欢的"收费桥梁"型生意——一次接入,长期收过桥费。** Function $2.5B 估值、17 个月翻 13 倍已经验证。

## 2.2 经济护城河四象限

| 护城河类型 | 强度 | 评估 |
|---|---|---|
| **无形资产(品牌/IP)** | 暂无 ⚠️ | Mark Hyman 式医学 IP 是 Function 的 30% 估值锚——健康知己**还没有这个人**,这是最大的 P0 风险 |
| **转换成本** | 极强 ★★★★★ | 5 年个人健康数据 + AI 教练上下文记忆 + 家庭账户 = 单一用户的退出代价指数级递增 |
| **网络效应** | 弱 ★★☆☆☆ | 用户之间不直接产生价值。**除非引入"家庭账户"(本人+父母+子女),网络效应才打开** |
| **成本优势** | 强 ★★★★☆ | 不做硬件 + 借用美年/瑞慈线下网络 + 借用喜马拉雅声音生态 = 单位经济模型远优于 Whoop/Oura |

**护城河综合判定**:转换成本 + 成本优势的双重叠加 = 真护城河。**但缺无形资产(IP)这一环,会导致冷启动期 CAC 爆炸。**

## 2.3 死亡反转推演 · Top 3 死穴

|---|---|---|---|

## 2.4 安全边际判断

- 美国对标 Function 17 个月估值翻 13 倍——意味着这个赛道每延迟 6 个月入场,成本翻倍

**LTVI 终判:这是值得重仓 5-10 年的好生意,但前提是医学 IP 合伙人 90 天内必须锁定。**

# 第四部分 · 【核心】你 5 个问题的答案

## 4.1 核心切入点是什么?

**不是**"中国唯一的个人健康整合大脑"(老余原方案,覆盖太宽,No.2 试金石不通过)。

**而是**:

> **「围绝经主权」**——做 35-55 岁高净值中产女性的「围绝经期 / 中年代谢拐点 / 雌激素健康主权」一体化 AI 健康陪伴管家。

### 这个切入点为什么是"切肤的取舍"

- **明确放弃**:男性用户(0-3 年内不做)、25-35 岁年轻女性(产品力不匹配)、慢病已确诊人群(医疗合规线)、低线城市下沉用户
- **明确聚焦**:35-55 岁、家庭年收入 50w+、一线及强二线、自费体检 ≥ 1 次/年的女性
- **一句话产品定义**:
  > "我们陪你穿越围绝经,把这段最艰难、最被忽视、决定你 60 岁后健康分水岭的 10 年,变成你健康复利的拐点。"

### 这个切入点用 5 块试金石复测

| 试金石 | 评分 | 改进 |
|---|---|---|
| 1. 诊断力 | ★★★★★ | 围绝经是真实痛点 + 国内零系统化供给 |
| 2. 取舍 | ★★★★★ | 主动放弃 95% 人群,有切肤之痛 |
| 3. 前置指标 | ★★★★ | "围绝经识别准确率"、"激素六项+ApoB+DXA 三联档案完整度"等可定义 |
| 4. 行动连贯 | ★★★★ | 喜播用户池 + 喜马拉雅声音 + 老余医学 IP 强制咬合 |
| 5. 重力对抗 | ★★★★★ | 围绝经文化在中国是禁忌话题,产品本身就是在抵抗社会沉默 |

**伪劣浓度评分:4.5 / 5.0** — 这是有血肉的策略,不是"愿望清单"。

### 这个切入点为什么不会是"小生意"

- 中国 35-55 岁城市女性约 1.2-1.5 亿人,其中高净值 + 健康觉醒约 800-1500 万
- 如果取 1% 用户、平均年费 1.5w → **市场规模 12-22 亿 ARR**
- 这只是灯塔阶段。验证后降维做"中年家庭健康"(本人 → 父母 → 子女),再降维做"全女性生命周期"——Tesla 路径

**比"中国整合大脑"模糊愿景更具体、更可执行、且更可能先跑出 Function 量级。**

## 4.2 核心人群的选择

### 用户画像 · 精确到画质

| 维度 | 内容 |
|---|---|
| 年龄 | 35-55 岁,核心 **40-50** |
| 性别 | 女性 |
| 城市 | 一线 + 强二线 |
| 家庭年收入 | 50w+ |
| 个人可支配 | 10w+ |
| 教育 | 本科+,信息检索能力强,**不信权威但信数据** |
| 职业 | 中高管 / 创业者 / 高知专业人士 / 高净值家庭主理人 |
| 心态触发点 | 已经为父母被慢病折磨而焦虑 + 自己开始为"高质量长寿"付费 |
| 媒介行为 | 小红书深度、微信高粘性、**听喜马拉雅**(关键)、自费体检、海外医疗咨询 |
| 现有支出 | 美容/保养/医美 5-15w/年、教培 3-10w/年、保健品 1-3w/年 |

### 为什么是她们 · 5 个理由

1. **支付意愿最强**:35-55 岁女性是中国"健康觉醒消费"的最大蓝海——美容/保养/医美/教培/保健品总支出 10-30w/年,其中 30-50% 是无效或负效消费,**可以被一个 1-8w 年费的健康主权产品收编**
2. **付费决策最快**:她们是家庭的"健康主理人"——既给自己买,也给老公、父母、孩子买。**1 个高净值女性用户 = 1.5-3 个潜在家庭账户**
3. **痛点最聚焦**:围绝经期(40-55 岁)在中国几乎是完全空白的医疗服务领域——西医诊室 5 分钟、中医玄学化、保健品收割
4. **认知最匹配**:她们既懂 Whoop/Oura,又信 Peter Attia / Dr. Mark Hyman / Mary Claire Haver——**已经被全球叙事教育好了,只缺中国版供给**
5. **喜播现成用户池**:这是**你蒋德铭手里最具体的、唯一不可复制的资产**

### 为什么不是男性企业家(老余画像)

不是不做,是**做不了主战场**:
- 男性企业家是稀缺人群,绝对人数小
- 男性健康觉醒的决策周期长(平均 3-5 年从体检异常到付费行动)
- 男性更倾向单独工具(Whoop/Oura)而非陪伴关系
- 健康产品里**女性是 70% 的家庭决策方** — 抓住女性 = 抓住男性 = 抓住家庭

**老余应该自己做男性 / 高净值企业家这条线作为第二灯塔。但主灯塔应该是 35-55 高净值女性。**

## 4.3 在什么场景下她们遇到什么痛苦?

### 6 个具体痛点场景 · 每个都是 PMF 的撬点

| # | 场景 | 痛苦 | 现有方案的失败 | 我们的解法 |
|---|---|---|---|---|
| 1 | 拿到 5 年体检报告 | Lp(a)、ApoB、雌激素六项、TSH、维生素 D——医生 3 分钟讲完,自己一头雾水 | 体检机构不深读、私立医院贵且短、AI 工具(豆包/文心)无个人数据 | **个人健康知己档案** + 跨年度趋势 + AI 个性化解读 |
| 2 | 突如其来的潮热/失眠/情绪低落 | 不知道是激素、压力、还是甲状腺;西医诊室没时间细问;百度搜出来全是恐慌 | 现有产品都是"症状对症"非"系统归因" | **围绝经多源数据归因引擎**(激素 + HRV + 睡眠 + 情绪日记) |
| 3 | 雌激素治疗(HRT)的决策焦虑 | 国际指南说可以用,国内医生说"看情况";自己查文献看不懂;不用怕骨折和心血管,用了又怕乳腺癌 | 国内无系统服务,只能去香港/海外 | **基于个人风险画像的 HRT 决策辅助** + 远程二诊网络 |
| 4 | 突然成为"家庭健康主理人" | 父母慢病用药管理、子女体检报告、自己围绝经——三代人健康挤在一个 49 岁女人的脑子里 | 微信运动、Apple Health 都只服务个人 | **家庭账户**(本人 + 父母 + 子女三代健康整合) |
| 5 | 40 岁后身材失控 | 同样的饮食和运动,代谢突然"卡壳";每周健身 3 次仍持续增重;医美投了 10w 但仍觉得垮 | 健身教练只看体重、医美只看皮相、营养师不懂代谢 | **代谢拐点诊断 + 个性化干预**(HOMA-IR + 体成分 + HRV + 训练) |
| 6 | 圈层焦虑 | 同龄朋友圈在用 Function/Oura/Whoop,中国没有真正对应的高端方案 | 中国市场无对标产品 | **健康知己·围绝经总管家**(年费 3-8w) |

### 6 个场景的 ISOEF 落地切口

按 AI 原生方法论(ISOEF + CIAO),这 6 个场景每一个都能定义成一个 PA(流程智能体):
- 痛点 1 → "体检解读 PA"
- 痛点 2 → "围绝经归因 PA"
- 痛点 3 → "HRT 决策辅助 PA"
- 痛点 4 → "家庭健康主理 PA"
- 痛点 5 → "代谢拐点 PA"
- 痛点 6 → "总管家服务 PA"

**6 个 PA 串成 1 个 IPA(集成流程智能体),就是产品 MVP 的核心架构。这是 ISOEF 给我们的工程化路径。**
