# 健康知己 · 长寿主权 · 男性灯塔 V1

> AI 驱动的个人健康仪表盘 —— 「数据证明你在变强」
> 面向 35-55 高净值男性的代谢/长寿主权管理原型

## 核心特性

- **夺回年龄战**:把"对抗衰老"反转为"主动夺回失去的年龄",生物年龄估算 + 向上的正反馈曲线
- **5 道健康防线**:四骑士(心血管/代谢/癌症/神经/肌骨)中文化,零认知障碍
- **今天该做的 3 件事**:AI 参谋每日聚焦,完成即时反馈(Claude Code 式正激励)
- **12 个关键指标**:每项带测量时间 + 数据来源 + 目标达成日期
- **健康路线图**:过去 → 现在 → 未来里程碑的完整时间轴
- **算法完全透明**:生物年龄点开可见逐项账本 + 局限声明

## 技术栈

- 后端:FastAPI + PyMySQL
- 前端:单页 H5(Chart.js)
- 数据库:MySQL 8(`health_concierge`,28 张表 + 男性 ICP 战略表)
- 配色:深海军蓝 + 青绿(Bloomberg × Tesla 座舱风格)

## 本地运行

```bash
pip install -r requirements.txt
cp .env.example .env       # 填入你的数据库凭据
python3 health_app.py      # → http://localhost:8000
```

iPhone 同 WiFi 访问:`http://<本机IP>:8000`

## 环境变量

见 `.env.example`。**数据库凭据从环境变量读取,绝不硬编码。**
